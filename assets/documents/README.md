# Documentos

Coloque aqui os arquivos PDF (calendário escolar, regimento, comunicados, formulários etc.).
Cada documento deve ser cadastrado em `assets/js/data.js` (lista `documents`) com o caminho do arquivo, por exemplo:

```js
{ id: "calendario-2026", title: "Calendário Escolar 2026", category: "calendario", file: "assets/documents/calendario-2026.pdf", size: "1,2 MB", date: "2026-02-01", description: "..." }
```
