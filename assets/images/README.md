# Imagens

- `logo.svg` — emblema do colégio usado no cabeçalho e rodapé.
- `placeholders/` — imagens ilustrativas temporárias (SVG). Substitua pelas fotografias oficiais do colégio.

Para trocar uma imagem, basta salvar a fotografia (JPG/PNG/WebP) nesta pasta e atualizar o caminho correspondente
em `assets/js/data.js` ou diretamente no HTML da página.
Recomendações: fotos horizontais em 1600×900 px para banners e 1200×800 px para cards.
