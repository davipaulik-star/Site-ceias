# Imagens

## Logo / brasão oficial
- `logo.svg` — brasão principal (fundo claro). **Substitua este arquivo pelo brasão oficial do colégio** mantendo o nome `logo.svg`
  (ou salve como `logo.png` e troque a extensão nos arquivos HTML). Formato recomendado: SVG ou PNG com fundo transparente, mínimo 512 px.
- `logo-white.svg` — versão clara para fundos azuis (rodapé, hero, seções escuras). Se o brasão oficial funcionar sobre fundo escuro, pode ser o mesmo arquivo.
- `../icons/favicon.svg` — ícone da aba do navegador (use o mesmo brasão).

## Fotografias
- `placeholders/` — imagens ilustrativas temporárias (SVG). Substitua pelas fotografias oficiais.
- Para trocar uma imagem, salve a fotografia (JPG/PNG/WebP) nesta pasta e atualize o caminho em `assets/js/data.js` ou no HTML.
- Recomendações: 1600×900 px para banners e 1200×800 px para cards.
