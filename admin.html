Painel de avisos

Área da direção e da secretaria para publicar avisos, recados e datas importantes no site. O acesso é feito com um token pessoal do GitHub de uma conta com permissão de escrita no repositório do site.

Opções avançadas
Como obter o token (uma única vez):
  1. Entre no GitHub com a conta autorizada (o criador do projeto pode adicionar a secretaria como colaboradora do repositório).
  2. Acesse Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. Selecione apenas o repositório do site e a permissão Contents: Read and write. Defina uma validade (ex.: 1 ano).
  4. Copie o token e cole acima. Ele fica salvo apenas neste navegador.
